# EmulatedCPU
A Java-based Virtual CPU Simulator with registers, memory, ALU, and program counter. It runs an 8-bit fetch-decode-execute cycle using a custom instruction set. Level 1 includes 4 registers, 256 bytes of memory, and basic instructions. Level 2 adds branching, 16-bit instructions, an assembler, debugger, and later a GUI.

A personal project to learn computer architecture by implementing an 8-bit CPU emulator.

Goals

Implement registers

Implement memory

Build an instruction set

Execute machine code programs


Status : Work in progress.

Technologies : Java
